📖 How to Add a Telegram Account

⚠️ IMPORTANT: You must enter your API ID and API Hash in the 🔑 Telegram API Credentials section below before you can add any account. Without these, account login will fail.
  1. Go to my.telegram.org → Log in → API development tools → copy your API ID and API Hash
  2. Enter them in the 🔑 Telegram API Credentials form below and click Save Credentials
  3. Scroll to ➕ Add Telegram Account — enter your phone number with country code (e.g. +8801XXXXXXXXX)
  4. Click Send Code — Telegram will send a code to your Telegram app
  5. Enter the verification code and click Verify
  6. If you have 2FA enabled, enter your 2FA password when prompted
  7. ✅ Done! The account appears in your Connected Accounts list below

💡 Use accounts that belong to you only. Do not use accounts that are currently logged in on other devices simultaneously.

🎬 Auto Video Poster

📦 Upload Videos

All supported videos inside all selected ZIPs are added to one queue.
🔐 Every video is remembered on Telegram the first time it is posted, so the campaign keeps running even after a redeploy wipes the server disk. For very large libraries, attach a Railway volume and set AUTO_POST_MEDIA_DIR=/data/auto_post_media (used automatically when a volume is mounted at /data), then top the library up any time with ➕ Add videos on the campaign card.
💾 The selected Telegram account's Saved Messages will be scanned for video messages. The bot stores message IDs instead of copying all videos to Railway storage.
0 channels
Accepted: @username, username, t.me/username, t.me/+invite, t.me/c/…. The selected account must be able to post in each channel.
Optional — leave empty to post with no caption.
If you add more than one, a random caption is picked per round and every channel in that round gets the same one. Placeholders work in every box: {filename} {name} {index} {total} {channel}
⏱️ One round posts one video to every channel, then the next round starts at this interval — measured from the previous round's start, not from its finish. So if a round itself takes 8 minutes and you set 3, the rounds run back-to-back rather than waiting 11 minutes. Set Minimum = Maximum for a fixed interval (e.g. 3 – 3 minutes).

ℹ️ How it works

  • Choose multiple ZIP files or Telegram Saved Messages as the video source.
  • Each channel gets its own random video queue.
  • Every round waits your chosen timer range (for example 5–15 minutes) before posting again.
  • When a channel finishes all videos, its queue automatically reshuffles and starts again from a new random cycle.
  • Pause/resume is available for each campaign.
  • Caption placeholders are replaced automatically.
